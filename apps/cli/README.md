# @swarmtales/cli

The swt command line: `swt run`, `swt resume`, `swt log verify`, `swt report`, `swt replay`, `swt scan` and
`swt experiment run` / `analyse`.

`swt --help` lists the commands, `swt <command> --help` the flags and the exit codes of one. The reference page is
[`docs/reference/cli.md`](../../docs/reference/cli.md); it also holds the format of the hand file (`--hand`). The
table both are written from is `src/flags.ts` (`FLAGS`, `COMMANDS`).
