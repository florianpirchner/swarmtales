# Errata of the M4 specification (kept by the integrator)

Corrections to [`11-m4-spec.md`](11-m4-spec.md) found while building: every difference between the specification
and the code that a builder or the integrator of M4 reported. The code on `rewrite/develop` follows this file where
the two differ. Decisions of principle are in `DECISIONS.md` section 9 (A42 to A46). Written by issue M4-63 from the
integrator's list of the merged issues and the bodies of their squash commits, each row checked against the
repository at commit `41e6371`; a difference nobody reported is not here.

The rows H1 to H31 are the integrator's list E1 to E31 in the same order; the commit bodies of M4-64 and M4-63 and
`RESUME.md` name them by those numbers ("errata E1", "E16"). The letter H follows G of M3, because E is taken by the
errata of M1. The rows from H32 on are differences stated in the commit bodies or in A42 to A46 that the list did
not hold.
